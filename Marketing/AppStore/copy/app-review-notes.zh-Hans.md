# App Review Notes 草稿（简体中文参考版）

App Store Connect 的 **App Review Information → Notes** 只接受一份文本，实际提交时请使用
[英文版](app-review-notes.en-US.md) 中的方框内容——审核人员读的是英文。这份中文版是给项目
方核对用的：确认审核说明里写的每一句话，都是你愿意为之负责的。

## 提交给审核的内容（对应英文方框，逐段对照）

**这是什么应用。**
ApexTerminal 是一个 SSH 客户端。它在用户自己已有的服务器上打开交互式 SSH 会话，分配 PTY，
并用内置的终端模拟器渲染输出。用户在会话里看到的一切，都来自他们自己的远程主机；应用本身
不执行任何命令，也不通过我们的任何服务器中转。

没有账号、没有登录、没有注册，也没有服务端组件。应用内没有任何需要额外付费的项目：没有分级、
没有试用。上架文案里描述的每一项能力，都在这个二进制里。

**怎么测试。**
需要一台审核人员能连上的 SSH 服务器和一份凭据。在 Mac 上，打开"系统设置 → 通用 → 共享 →
远程登录"就够了，应用可以通过本地网络连上去。

1. 启动应用，接受一次条款页面。
2. 点 + → 新建连接。填写主机名；端口不是 22 时填端口；填写用户名。端口和用户名都可以留空，
   留空表示"用默认值"或"连接时再问我"。
3. 选择认证方式：
   - 密码：选 Password，连接过程中应用会弹出输入框。
   - 密钥：设置 → 密钥 → + → 生成。把它显示的公钥复制到服务器的 `~/.ssh/authorized_keys`，
     然后在连接里选中这把密钥。
4. 点这条连接。应用会先显示服务器的主机密钥指纹并等待确认——这一步是有意为之，也是截图之一。
5. 确认之后会出现 shell 提示符。随便敲一条命令；跑 `vim` 或 `top` 可以看到全屏程序。

键盘上方的辅助键行提供 Esc、Tab、Ctrl、方向键和翻页键。先点 ctrl 再点字母即发送控制字符，
所以 ctrl 之后按 c 就是中断。

**权限。**
Face ID / Touch ID（`NSFaceIDUsageDescription`）只用于两件由用户自己开启的可选事情：开启
应用锁后解锁应用，以及使用一把用户选择用生物识别保护的私钥。两者都不是使用应用的前提。
首次连接同网段的服务器时，iOS 可能会请求本地网络权限——那就是 SSH 连接本身。

**二进制里有、但没有对外宣传的功能**（对应指南 2.3.1，必须逐项说明）：

- 通过 Cloudflare Tunnel 连接受 Cloudflare Access 保护的主机。协议已实现，并针对一个复现
  边缘行为的本地服务器做过测试，但还没有通过真实的 Cloudflare 账号完成过一次连接。上架文案
  里没有出现 Cloudflare；本应用与 Cloudflare 无从属关系，也未获其背书。
- 通过 SSH 连接或直连查看远程屏幕（VNC）。已针对 LibVNCServer 测试，尚未对 macOS 屏幕共享
  或 Linux 桌面运行过。
- 一个用于解释命令和输出的助理。设备支持时用设备本身的模型，否则使用用户在设置里填写的
  服务端地址与 API key。应用不内置任何 key，没有 key 就不会发出请求；发送前会把要发送的
  内容展示给用户，建议的命令只会被填入命令行，不会被执行。
- 通过用户自己的私有 CloudKit 数据库同步连接、片段、已知主机和公钥元数据。默认关闭。
- 用于打开已保存连接的快捷指令。
- 首次运行的简短引导，可以在设置里重看。

**隐私。**
没有统计、没有埋点、没有广告标识符，也没有会收集数据的第三方 SDK。连接、密钥、片段和已知
主机都存在设备上；私钥保存在钥匙串里，带明确的保护等级，应用不显示也不传输它们。命令历史
默认关闭，关闭时删除的是文件本身。

**内容。**
应用显示的是用户自己服务器送来的内容。除了界面本身，它没有自带内容，也没有任何浏览、搜索或
发现第三方内容的入口。

## 给提交者的备注（不提交给审核）

* **截图来源。** 24 张最终图全部来自这个构建在模拟器中的运行，由应用自身界面驱动，连接的是
  容器里三台隔离的真实 OpenSSH 服务器。画面上的账号与主机名（`deploy`、`edge-01`、
  `db-primary`、`build-runner`）都是虚构的，地址位于 RFC 6761 保留的 `*.localhost` 之下。
  详见 [`FEATURE_AUDIT.md`](../FEATURE_AUDIT.md) 第 7 节。
* **出口合规。** 工程没有设置 `ITSAppUsesNonExemptEncryption`，提交时 App Store Connect 会
  询问。应用使用的是 SSH——标准密码学，非自研，用于认证和保护连接——通常属于豁免情形，
  但这个答案要由提交者自己给出，某些司法辖区还需要年度自分类报告。请认真回答，不要一路点过去。
* **年龄分级。** 应用本身没有任何超出 4+ 的内容。界面是一个终端；内容是用户服务器打印出来的
  东西——所有 SSH 客户端都处在同样的位置。
* **法律文本仍是占位符。** 生效日期、开发者法定名称、适用法律与管辖地，三种语言的
  `App/Resources/Legal/` 里都还空着，也没有经过律师审阅（见 `PROJECT_STATUS.md` B-5）。
  提交前必须填好：同意页在首次启动时就会展示它们，审核人员会读到。
* **版本号。** 本次审计的构建是 `0.1.0 (1)`。若以 1.0 提交，需要提升 `MARKETING_VERSION`
  并重新取景——`scripts/capture.sh` 会把整套流程重跑一遍，`CAPTURE_MANIFEST.json` 记录每张图
  来自哪个构建。
