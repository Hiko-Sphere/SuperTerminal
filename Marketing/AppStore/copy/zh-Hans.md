### Description

```
SuperTerminal 是一个为 iPhone 和 iPad 写的 SSH 客户端。它在你自己的服务器上打开一个真正的交互式会话，分配真实的 PTY，并用自带的终端模拟器把远端送来的每一个字节画出来——不是网页里的终端，中间没有我们的服务器，也不需要注册任何账号。

你敲下的命令，运行在你自己的远程主机上。SuperTerminal 只是那台终端，真正干活的是你连上去的服务器。

一个真正的终端
自己实现的 VT/ANSI 模拟器。256 色、备用屏幕、鼠标上报，以及正确的字符宽度——中日韩文字、emoji、组合符号和旗帜序列，都按 Unicode 17.0.0 的表来算。编辑器和分页器照常工作：每次改动，测试都会通过一条真实的 SSH 连接跑一遍 vim 和 less，包括在编辑途中改变窗口大小。

不止一台机器
同时打开多台服务器。会话彼此独立，来回切换不需要重连。每个连接都会报告服务器在跑什么系统——macOS、Linux、各种 BSD 或 Windows——通过一条单独的通道探测得到；你比它更清楚的时候，也可以手动指定。

主机密钥，会问过你
第一次连到一台服务器时，SuperTerminal 会把对方出示的密钥指纹摆在你面前，然后等你回答。之后密钥如果变了，它会明确告诉你，并且停在那里，直到你做出决定——绝不会静默通过。已知主机可以随时查看，也可以删除。

密钥留在这台设备上
在应用里生成 Ed25519 或 ECDSA P-256 密钥，把公钥复制到服务器，私钥留在钥匙串里——界面上不显示它，应用也不会把它发到任何地方。创建密钥时，可以要求之后每次使用都先过一次 Face ID 或 Touch ID。已有的 OpenSSH 私钥可以导入，包括带口令保护的。你手上原有的 RSA 密钥依然可用（rsa-sha2-256 与 rsa-sha2-512；SHA-1 的 ssh-rsa 是有意不支持的）。

为手机而写，也为 iPad 而写
一排辅助键，补上软键盘没有、终端却离不开的 Esc、Tab、Ctrl、方向键、Home、End 和翻页键。双指捏合改变字号，远端程序会同步收到新的窗口尺寸。在 iPad 上：终端旁边是常驻的边栏，需要时可以再开一个窗口，外接键盘的快捷键也都落在你以为的地方——新建连接、命令面板、上一个/下一个会话、关闭、调整字号。

把翻过去的内容找回来
在正在运行的会话里搜索回滚缓冲，匹配数会算给你看，可以逐个跳转，跨越自动换行的匹配也找得到。命令面板用的是真正的模糊排序，能一次搜到连接、已开会话、片段和操作。片段只会把文字放到命令行上，等你自己按下回车，而不是替你执行。

默认就很安静
命令历史默认关闭，你不打开它就不会记录；关掉的时候删除的是文件本身，不只是列表。从终端复制的文本会从剪贴板过期，默认一分钟。多行粘贴会先问一句。终端可以在应用切换器里被遮住。应用本身也可以用一个独立的密码锁上，前面再加一道 Face ID 或 Touch ID。

隐私
没有账号，没有埋点，没有统计。连接、密钥和片段都在你自己的设备上。你敲了什么、服务器回了什么，开发者都收不到——因为它们除了你指定的那台服务器，哪儿也没去。

界面提供英文、简体中文和繁体中文。终端里的输出永远不翻译。

需要 iOS 或 iPadOS 17.0 及以上。服务器由你提供，SuperTerminal 负责连上去。
```

## 核心功能，逐条

可以直接用在官网、发布贴或需要要点列表的场合。

1. **真正的交互式 SSH 会话** —— 在你自己的服务器上分配一个真实 PTY，而不是逐条执行远程命令。
2. **自带终端模拟器** —— 256 色、备用屏幕、鼠标上报，中日韩文字与 emoji 的宽度都算对。
3. **全屏程序跑得起来** —— `vim` 和 `less` 由测试通过真实 SSH 连接跑过，包括编辑途中改尺寸。
4. **多台服务器同时在线** —— 会话互相独立，每个连接都会报告服务器跑的是什么系统。
5. **主机密钥会问过你** —— 首次连接先看指纹；密钥变了就停下来，等你决定。
6. **密钥在设备上生成** —— Ed25519 或 ECDSA P-256，私钥进钥匙串，可以要求 Face ID 或 Touch ID。
7. **回滚缓冲可搜索** —— 匹配数看得见，可以逐个跳转，跨行匹配也找得到。
8. **辅助键与硬件快捷键** —— 手机上补齐 Esc / Tab / Ctrl / 方向键；iPad 上有边栏、第二个窗口和键盘快捷键。
9. **片段与模糊命令面板** —— 片段只放到命令行上，不替你执行；面板按匹配质量排序，不是子串过滤。
10. **默认不留痕** —— 历史默认关闭，剪贴板会过期，应用本身可以上锁。

## 隐私与安全说明

* **没有账号、没有埋点、没有统计。** 开发者收不到任何数据。
* **没有中转。** 应用直接连到你写下的那台服务器。
* **私钥保存在钥匙串**，带明确的保护等级，界面上不显示，导出的内容里也不包含。
* **可以要求 Face ID 或 Touch ID** 之后才能使用某把密钥，这个选择在创建密钥时做出。
* **主机密钥会被校验**，首次连接时记录下来；之后有变化会被摆到你面前，而不是被吞掉。
* **命令历史需要你主动打开**；关掉时删除的是文件。
* **复制的终端文本会过期**，默认 60 秒后从系统剪贴板消失。
* **终端可以在应用切换器里被遮住。**
* **应用可以上锁**，用一个独立的密码，前面再加生物识别。

以上是这个应用做了什么，不是对任何威胁的保证。项目的威胁模型写在 `SECURITY.md` 里。

## 首发版本功能摘要

> **这不是 App Store 的 "What's New" 字段。** 第一个版本没有"更新内容"可写；这份摘要是给
> 发布贴或支持页面用的。提交 1.0 时，What's New 留空，或使用 Apple 建议的首发文案。

SuperTerminal 0.1.0 是第一个版本，包含：

* 通过直连 TCP 的 SSH，支持 Ed25519、ECDSA P-256 和 RSA（SHA-2）密钥、带口令的密钥，以及密码；
* 首次连接记录主机密钥并明确询问；密钥变更走一条刻意"不好按"的确认路径；
* 密钥生成、导入，以及公钥的复制与分享，可选生物识别门槛；
* 终端模拟器：256 色、备用屏幕、鼠标上报、重排、选择、复制与搜索；
* 多会话并行、带退避的自动重连，以及重新打开上次那些机器的入口；
* 辅助键行、捏合调整字号、片段、模糊命令面板、硬件键盘快捷键；
* 应用锁、剪贴板过期、应用切换器遮罩，以及默认关闭的命令历史；
* 英文、简体中文、繁体中文。
