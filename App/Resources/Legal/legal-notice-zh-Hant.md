# SuperTerminal — 使用者須知

這是以淺白文字說明本應用程式如何處理您的金鑰。它不是隱私權政策或使用條款；它是在您將任何東西託付給本應用程式之前應該閱讀的頁面。

## 本應用程式會做的事

- 開啟通往您所新增之伺服器的 SSH 工作階段，直接連線或透過 Cloudflare Tunnel。
- 對於經隧道連線的主機，讓您在系統瀏覽器中登入 Cloudflare Access，並使用登入產生的權杖代表您開啟隧道；若您為該連線提供了 Access 服務權杖，則直接出示該權杖，無需瀏覽器。本應用程式絕不會看到您的 Cloudflare 密碼。本應用程式絕不會看到您的 Cloudflare 密碼。
- 將您的連線、金鑰、密碼、Access 權杖、host key 與指令片段儲存在您的裝置上，讓您不必重新輸入。
- 可選擇透過您自己的 iCloud 帳號，在您自己的裝置之間同步連線、指令片段、host key，以及您選擇的私密金鑰。密碼絕不同步。

## 本應用程式不會做的事

- 它沒有帳號、沒有伺服器、沒有分析工具、沒有當機回報程式，也沒有遙測。沒有任何內容傳送給開發者。
- 它絕不會將憑據傳送至任何地方，除了傳送至您正在驗證身分的伺服器，或將 Access 權杖回傳給 Cloudflare。
- 它絕不會削弱 TLS 檢查或 host key 檢查。沒有任何設定（無論隱藏與否）會在不詢問您的情況下接受無效的憑證或已變更的 host key。
- 它絕不會將您的終端機輸出寫入磁碟。回捲緩衝區僅存於記憶體。
- 除非您開啟指令歷史，否則它不記錄您輸入的內容。關閉即刪除記錄，而非隱藏。
- 它不會將機密資訊自指令歷史中過濾掉，因為一個大致有效的過濾器比沒有過濾器更糟。若您開啟歷史並在指令列輸入密碼，它會被記錄下來，如同您的 shell 會記錄一樣。
- 除非您開啟 iCloud 同步，否則它不同步任何內容。

## 您的金鑰存放於何處

- **在裝置上：** 存於 Apple 的 Keychain 中，僅在裝置解鎖時可讀取。iCloud 同步關閉時，每個項目都標記為僅限本裝置，無法經由 iCloud Keychain 或還原至其他裝置的備份傳輸。您可以額外以 Face ID 或 Touch ID 鎖定金鑰。以此方式鎖定的金鑰與目前註冊的生物特徵綁定；註冊新的臉孔或手指會使其無法使用，因此得知您裝置密碼的人無法將自己加入並讀取它。
- **在 iCloud 中，僅在您開啟同步時：** 私密金鑰僅在您為它選擇了 iCloud Keychain，且它*未*受 Face ID/Touch ID 保護時才會同步。它會透過 iCloud Keychain 傳輸，Apple 對其進行端對端加密。密碼絕不同步。受生物辨識保護的金鑰絕不會離開裝置。Apple 不允許，本應用程式也不會嘗試。
- **其他任何地方都沒有。** 私密金鑰絕不會傳送至伺服器；伺服器看到的是以該金鑰產生的簽章。

## 受保護的事項及其方式

**有人冒充您的伺服器。** 每次連線都會驗證伺服器的 host key。您從未連線過的伺服器必須由您確認，其 SHA-256 fingerprint 會顯示在畫面上。金鑰自上次以來已變更的伺服器會被拒絕；本應用程式會顯示兩個 fingerprint 並等待。斷線後的重新連線也會經過同樣的檢查。

**有人介於您與 Cloudflare 之間。** TLS 由作業系統驗證。本應用程式沒有任何方式可接受不良憑證。

**有人操控 Cloudflare 登入流程。** 本應用程式只接受由 Cloudflare 簽署的登入資訊，且僅限於 `cloudflareaccess.com` 之下的登入網域。伺服器無法透過本應用程式將您導向假的登入頁面。

**有人竊取或重複使用 Access 權杖。** 權杖在傳送前會檢查簽章、受眾、發行者與有效期限。用於某個 Access 應用程式的權杖無法用於另一個。

**您的記錄。** 您輸入的任何內容與伺服器印出的任何內容都絕不會被記錄。主機名稱與權杖在每行記錄寫入時即被遮蔽，而非事後清除，因此診斷匯出是所記錄內容的副本。去識別化只保留伺服器名稱的最後兩段（`<host:…>.example.com`）；IP 位址會變成 `<ip>`。

**重試。** 只有網路與隧道失敗會自動重試。被拒絕的 host key、失敗的憑證檢查、被拒絕的密碼或被拒絕的 Access 登入會停止並向您顯示錯誤。本應用程式不會越過安全檢查進行重試。

**傳輸中的加密。** SSH 僅使用認證加密（authenticated encryption）演算法：AES-GCM、ChaCha20-Poly1305，或搭配 encrypt-then-MAC 的 AES-CTR。沒有 CBC、沒有 RC4、沒有任何不附完整性驗證的加密模式。本應用程式未自行實作任何密碼學；每一個基礎元件都來自 Apple 的 CryptoKit、swift-crypto、libsodium 或 OpenBSD 的 bcrypt_pbkdf。

**貼上。** 多行貼上在傳送前會請求確認，除非您在設定中關閉該功能。

**App 切換器。** 「在 App 切換器中隱藏內容」開啟時（預設開啟），只要本應用程式不在前景，其 logo 就會蓋住終端機，因此系統的 App 切換器快照不會顯示任何終端機內容。

## 您必須檢查的事項

首次連線至某台伺服器時，本應用程式會顯示該伺服器的金鑰 fingerprint 並請您確認。請將其與伺服器本身回報的內容比對（對 host key 檔案執行 `ssh-keygen -lf`，或詢問其管理者）。若您未經檢查就確認 fingerprint，您就是在信任回應的任何一方；本應用程式在首次連線時無法分辨其中差異。之後，已變更的金鑰會被拒絕，直到您檢視兩個 fingerprint 並作出決定為止。本應用程式不會越過該提示進行重試。

## 自動重新連線

若連線因網路或隧道而中斷，本應用程式會重新連線。它不會重試被拒絕的密碼、已變更的 host key 或失敗的憑證檢查；這些會停止並等待您處理。重新連線後的 shell 是新的：工作目錄不同，沒有任何程序在執行。本應用程式會在終端機中畫一條標有其自身名稱的分隔線，讓您看見中斷發生的位置。

## iCloud，一段話說明

開關處於關閉狀態，直到您開啟為止。開啟時：連線清單、指令片段、已知的 host key 與您金鑰的非機密資訊會進入您的 iCloud 私人資料庫；您為其選擇了 iCloud Keychain 的私密金鑰（若非生物辨識金鑰）會經由 iCloud Keychain 傳輸；密碼絕不傳輸。絕不同步：生物辨識金鑰、指令歷史、最近開啟的工作階段清單、診斷資訊。Access 權杖留在登入的那台裝置上。開發者無法讀取其中任何內容；Apple 能否讀取取決於您 iCloud 帳號的設定，而非本應用程式。關閉即停止同步。「刪除所有資料」也會清除 iCloud。自另一台裝置同步而來的 host key，對於本裝置尚未接觸過的主機，在此視為受信任，與您在此確認的金鑰相同，因此控制您 iCloud 帳號的人可以植入一把；而與本裝置已信任之金鑰不同的同步金鑰則不會被套用；「設定 → iCloud」會顯示這項分歧，由您選擇保留哪一把金鑰。由於您的 Apple 帳號現在能夠觸及您的連線清單與 host key，請為其保持開啟雙重認證。

## 您必須自行做的事

1. **驗證首次的 fingerprint。** 若您確認了攻擊者的 fingerprint，之後對該身分的每次連線都已遭入侵，且本應用程式無從得知。
2. **認真看待已變更的金鑰。** 若本應用程式表示金鑰已變更，而您並未重新安裝或更換伺服器的金鑰，請停下來詢問管理者。
3. **保持設定裝置密碼。** 上述每項保護都假設裝置在您未使用時處於鎖定狀態。
4. **對重要的金鑰使用 Face ID 或 Touch ID。** 每次連線只需看一眼，卻能讓被竊取的裝置密碼不足以得逞。
5. **若您開啟 iCloud 同步，請確保 iCloud 帳號的安全。** Apple 帳號開啟雙重認證是最低要求。
6. **開啟歷史時，不要在指令列輸入機密資訊。** 您輸入的內容就是被儲存的內容。
7. **在伺服器上撤銷，而不只是在手機上。** 自本應用程式刪除金鑰並不會將公開金鑰自伺服器的 `authorized_keys` 中移除。遺失裝置意味著要在該處撤銷，並在您的 Cloudflare 儀表板中撤銷 Access 工作階段。
8. **不要安裝您不信任的根憑證。** 本應用程式信任作業系統的信任儲存區。

## 本應用程式無法保護您免受的事項

- 已遭入侵的裝置，或他人在其上安裝的受信任根憑證。
- 您未經檢查就確認的首次連線 fingerprint。
- 營運您網路的人看見您連線至哪些主機名稱。內容是加密的；目的地並未隱藏。
- 能夠解鎖您的裝置並開啟本應用程式的人。他們可以使用任何金鑰未受生物辨識保護的已儲存連線。
- 控制您 Apple 帳號的人，若 iCloud 同步已開啟。
- 您從終端機複製的任何內容預設會在剪貼簿上保留一分鐘，之後由 iOS 移除；可在「設定 → 安全性」中更改時間或關閉此功能。從金鑰清單複製的公開金鑰會一直保留，直到被取代。
- 有一個相依套件 libsodium 是以其維護者提供的預先建置二進位檔納入，而非從原始碼建置。其角色僅限於開啟密封的 Cloudflare 登入結果（其後會再獨立驗證），以及 ChaCha20-Poly1305 SSH 加密演算法。
- 不支援 Cloudflare 的 FedRAMP 端點。

## 清除

**設定 → 刪除所有資料** 會關閉每個工作階段，並自裝置移除每一筆連線、金鑰、密碼、Cloudflare 登入、指令片段、歷史項目、最近開啟的工作階段清單與每一把已知的 host key，若同步曾開啟，亦會移除本應用程式在 iCloud 中的資料。單一 host key 也可在 **設定 → 已知主機** 中移除。刪除本應用程式會移除其檔案，但 iOS 不承諾一併移除 Keychain 項目，因此請先執行「刪除所有資料」。兩者都不會觸及您的伺服器或您的 Cloudflare 帳號；請在該處自 `authorized_keys` 移除公開金鑰或撤銷 Access 工作階段。
