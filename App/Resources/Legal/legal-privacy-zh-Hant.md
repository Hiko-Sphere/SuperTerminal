# SuperTerminal — 隱私權政策

**生效日期：** [effective date]

SuperTerminal 不收集任何關於您的資料。開發者不營運任何伺服器，因此資料無處可去。本頁具體說明本應用程式儲存哪些內容、儲存於何處，以及哪些內容會離開您的裝置，因為「我們重視您的隱私」並不是任何人能夠查證的說法。

## 簡短版本

- 您的金鑰、密碼與連線留在您的裝置上，存於 Apple 的 Keychain 與本應用程式自身受保護的儲存空間中。
- 唯一的網路流量是傳送至您所連線的伺服器，以及（就經隧道連線的主機而言）代表您傳送至 Cloudflare。
- 若您開啟 iCloud 同步，您的部分資料會儲存在您自己的 iCloud 帳號中。開發者無法讀取這些資料。
- 沒有分析工具、沒有當機回報程式、沒有遙測、沒有廣告、沒有帳號。

| 連線清單（名稱、主機名稱、使用者名稱、連接埠） | 應用程式儲存空間 | 裝置鎖定時加密 | 僅在您開啟 iCloud 同步時 |

| 已知的 host key | 應用程式儲存空間 | 鎖定時加密；排除於裝置備份之外 | 僅在您開啟 iCloud 同步時 |
| 指令片段 | 應用程式儲存空間 | 鎖定時加密；包含於裝置備份中 | 僅在您開啟 iCloud 同步時 |
| 設定 | 應用程式偏好設定 | 標準應用程式儲存空間 | 否 |
| 最近開啟的工作階段清單 | 應用程式儲存空間 | 連線名稱與時間，最多保留七天；鎖定時加密；排除於備份之外 | 否 |
| 終端機回捲緩衝區 | 僅存於記憶體 | 工作階段或本應用程式結束時即消失。絕不寫入磁碟 | 否 |

iCloud 同步關閉時，每個 Keychain 項目都標記為僅限本裝置。它無法經由 iCloud Keychain 傳輸，也無法從備份還原至其他裝置。

Face ID 與 Touch ID 完全由 iOS 處理。本應用程式絕不會看到您的臉部或指紋資料；它只會得知系統的檢查是否通過。以此方式保護的金鑰，在裝置上註冊新的臉孔或手指後即無法使用，因此得知您裝置密碼的人無法將自己加入並讀取該金鑰。

## 離開您裝置的內容

只存在三種網路流量，且三者皆由您選擇。

**1. 傳送至您所連線的伺服器。** SSH 流量，在您的裝置與伺服器之間端對端加密：您的使用者名稱、您金鑰的簽章或您的密碼、您輸入的內容，以及伺服器回傳的內容。當連線經由 Cloudflare Tunnel 傳輸時，Cloudflare 會轉送加密的 SSH 位元組，但無法讀取；host key 驗證保護您免受隧道本身的威脅。伺服器會保留自己的登入紀錄，如同任何伺服器一樣。

**2. 傳送至 Cloudflare，針對您標記為經隧道連線的主機。** 本應用程式會詢問主機由哪個 Access 應用程式保護、取得 Cloudflare 的簽署金鑰、在系統瀏覽器中開啟登入頁面、收取產生的權杖，並在開啟隧道時將該權杖出示給 Cloudflare。您的登入本身在瀏覽器中進行，與 Cloudflare 及您的身分提供者互動；本應用程式絕不會看到您在該處輸入的密碼。所有這些都傳送至 Cloudflare 自己的端點，如同您使用 Cloudflare 自家工具時一樣。Cloudflare 對此記錄哪些內容，受 Cloudflare 的隱私權政策及您與其之間的合約規範。

**3. 傳送至 iCloud，僅在您開啟時。** 請見下一節。

沒有任何內容傳送給開發者。沒有開發者的伺服器、沒有分析 SDK、沒有當機回報程式，也沒有追蹤網域。本應用程式在 App Store 的隱私權標籤標示「未收集資料」，因為這是事實。

如同任何 SSH 用戶端，您所在網路的營運者可以看見您的裝置連線至哪些主機名稱。連線的內容則是加密的。

## iCloud 同步

iCloud 同步處於**關閉**狀態，直到您在設定中開啟為止。開啟後：

- **您的連線清單、指令片段與已知的 host key** 會透過您自己的 iCloud 帳號，在本應用程式於該處的私人資料庫中同步，連同您 SSH 金鑰的非機密資訊（名稱、演算法、公開部分、fingerprint、建立日期，以及該金鑰是否受 Face ID/Touch ID 或密語保護、是否存放於 iCloud Keychain），以便清單在您的其他裝置上能夠對應理解。Apple 會在傳輸中與靜態儲存時加密這些資料。開發者無法存取這些資料。Apple 本身能否讀取，取決於您 iCloud 帳號的設定，而非本應用程式。
- **SSH 私密金鑰僅在您建立或匯入該金鑰時為它選擇了 iCloud Keychain，且它未受 Face ID 或 Touch ID 保護時才會同步。** 此時它會透過 iCloud Keychain（Apple 端對端加密的鑰匙圈同步）傳輸，前提是您的裝置已開啟 iCloud Keychain。**密碼絕不同步**；每台裝置都會再次向您詢問密碼。
- **受 Face ID 或 Touch ID 保護的金鑰絕不同步。** Apple 不允許，本應用程式也不會嘗試。它們只存在於您建立或匯入它們的裝置上。
- **指令歷史、最近開啟的工作階段清單與診斷資料絕不同步**，無論開關狀態為何。
- **Cloudflare Access 權杖、服務權杖與設定不屬於同步範圍。** 每台裝置各自登入 Access，或再次向您詢問服務權杖。

同步的意思是「在每台登入您 Apple 帳號的裝置上都相同」。您在一台裝置上信任的 host key，在其他裝置上對於它們尚未接觸過的主機也視為受信任。若另一台裝置傳來的金鑰與本裝置已信任的金鑰不同，本應用程式不會套用它：本裝置保留自己已有的金鑰，並在「設定 → iCloud」中顯示這項分歧，由您選擇保留哪一把金鑰。您允許同步的金鑰會存在於每台受信任可使用 iCloud Keychain 的裝置上。

由於您的 iCloud 帳號因此能夠觸及您的連線清單、您儲存的 host key，以及您允許同步的任何金鑰，該帳號便成為保護您伺服器的一環。請為您的 Apple 帳號保持開啟雙重認證。

關閉開關即停止同步；已在各裝置上的資料會留在該處。**刪除所有資料**會將本應用程式的資料自 iCloud 以及本裝置移除。若您的另一台裝置已經同步了副本，請在該裝置上也執行「刪除所有資料」。

## 指令歷史

預設關閉。若您開啟，本應用程式會記錄您最近輸入的 500 筆指令，僅存於本裝置，裝置鎖定時加密，並排除於備份之外。它不會過濾機密資訊：在指令列輸入的密碼會被原樣記錄，如同您 shell 自身的歷史記錄一樣。本應用程式不嘗試過濾這些內容，因為一個大致有效的過濾器會獲得超出其應得的信任。關閉歷史即刪除該檔案。之後再次開啟會從零開始。

## 診斷資料

在「設定」中可匯出診斷資訊，以協助處理支援問題。報告不包含任何指令、終端機輸出、密碼、金鑰或權杖，也不包含完整的主機名稱。主機名稱在每行記錄寫入的當下即以簡短的單向摘要取代，只保留名稱的最後兩段（`bastion.corp.example.com` 會變成 `<host:…>.example.com`；IP 位址會變成 `<ip>`），權杖則以其長度與摘要取代，因此匯出內容是所記錄內容的副本，而非可能有所遺漏的事後清理。報告只會顯示在螢幕上，除非您選擇分享，否則不會儲存在任何地方。是否分享、與誰分享由您決定；本應用程式不會將其傳送至任何地方。若您將報告寄給開發者，其僅在回答您問題所需的期間內保留。

## 開發者收到的內容

本應用程式不傳送任何內容。若您寄電子郵件給開發者，您的電子郵件地址與您所寫的內容會在回覆所需的期間內保留。Apple 可能向開發者顯示彙總的 App Store 統計資料，以及（若您在裝置的「分析」設定中選擇了「與 App 開發者分享」）iOS 所收集的當機記錄。這是 Apple 的機制，載於 Apple 的隱私權政策中；本應用程式並未在其上增添任何內容，也不包含自己的當機回報程式。

## 您對自身資料的權利

本應用程式持有的一切都在您的裝置上或您自己的 iCloud 帳號中，受您控制。開發者處沒有任何副本，因此開發者沒有任何內容可應要求提供、更正或刪除。要查看您的資料，請開啟本應用程式。要刪除資料，請見下文。若您認為開發者仍持有任何關於您的資料，請寫信至 [developer contact email]。

## 刪除一切

**設定 → 刪除所有資料** 會關閉每個開啟的工作階段，並自本裝置移除每一筆連線、SSH 金鑰、已儲存的密碼、Cloudflare Access 登入、指令片段、指令歷史項目、最近開啟的工作階段清單與每一把已知的 host key，若同步曾開啟，亦會移除本應用程式在 iCloud 中的資料。單一 host key 也可在 **設定 → 已知主機** 中移除。

**刪除本應用程式** 會將其檔案自裝置移除。iOS 不承諾在刪除應用程式時一併移除該應用程式的 Keychain 項目，因此若您也希望金鑰、密碼與權杖一併消失，並在同步曾開啟時清除 iCloud，請先執行「刪除所有資料」。

這兩項操作都不會變更您伺服器上或 Cloudflare 處的任何內容。要在該處撤銷存取權，請自伺服器的 `authorized_keys` 中移除公開金鑰，或在您的 Cloudflare Zero Trust 儀表板中撤銷工作階段。

## App Store 隱私權標籤

收集的資料：無。追蹤：無。本應用程式的隱私權資訊清單宣告其使用的兩個須說明理由的 API（用於自身容器的檔案時間戳記，以及用於設定的標準偏好設定）、無收集的資料類型，亦無追蹤網域。

本應用程式是管理伺服器的工具，並依此在 App Store 上分級。它不收集任何人（不論年齡）的資料。
