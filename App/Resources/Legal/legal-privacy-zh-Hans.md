# SuperTerminal — 隐私政策

**生效日期：** [effective date]

SuperTerminal 不收集任何关于您的信息。开发者不运营任何服务器，因此数据无处可去。本页面具体说明本应用存储什么、存储在哪里以及哪些内容会离开您的设备，因为“我们重视您的隐私”并不是任何人能够核实的说法。

## 简短版本

- 您的密钥、密码和连接保留在您的设备上，存放于 Apple 的 Keychain 和本应用自身的受保护存储中。
- 唯一的网络流量是发往您所连接的服务器，以及（对于经隧道连接的主机）代表您发往 Cloudflare。
- 如果您开启 iCloud 同步，您的部分数据会存储在您自己的 iCloud 账户中。开发者无法读取这些数据。
- 没有分析、没有崩溃报告器、没有遥测、没有广告、没有账户。

## 本应用在您设备上存储的内容

| 数据 | 位置 | 保护方式 | 是否离开设备？ |
| --- | --- | --- | --- |
| 连接列表（名称、主机名、用户名、端口） | 应用存储 | 设备锁定时加密 | 仅当您开启 iCloud 同步时 |
| SSH 私钥 | Keychain | 仅在设备解锁时可读；可选择额外以 Face ID 或 Touch ID 加锁 | 从不发送到服务器；服务器看到的是签名而不是密钥。仅当您开启同步并为该密钥选择了 iCloud Keychain 时才会通过 iCloud Keychain 传输；受 Face ID 或 Touch ID 保护时绝不传输 |
| SSH 密码 | Keychain | 仅在设备解锁时可读 | 发送到您正在登录的服务器。不同步 |
| Cloudflare Access 令牌 | Keychain | 设备自重启后解锁过一次即可读取，以便设备在您口袋里时也能重新连接 | 仅发回 Cloudflare，作为您自己连接的凭据。不同步 |
| Cloudflare Access 服务令牌（仅当您为某个连接输入了它时） | Keychain | 仅在设备解锁时可读 | 仅发往 Cloudflare，作为该连接的凭据。不同步；随连接一起删除 |
| 已知 host key | 应用存储 | 锁定时加密；排除在设备备份之外 | 仅当您开启 iCloud 同步时 |
| 片段 | 应用存储 | 锁定时加密；包含在设备备份中 | 仅当您开启 iCloud 同步时 |
| 设置 | 应用偏好设置 | 标准应用存储 | 否 |
| 最近打开的会话列表 | 应用存储 | 连接名称和时间，最多保留七天；锁定时加密；排除在备份之外 | 否 |
| 终端回滚内容 | 仅内存 | 会话或本应用结束时即消失。从不写入磁盘 | 否 |
| 命令历史 | **除非您开启，否则不记录。** 开启后：应用存储，锁定时加密，排除在备份之外，最近 500 条命令 | 否。关闭的那一刻即删除 |

iCloud 同步关闭时，每个 Keychain 项目都标记为仅限本设备。它无法通过 iCloud Keychain 传输，也无法从备份恢复到另一台设备上。

Face ID 和 Touch ID 完全由 iOS 处理。本应用从不看到您的面容或指纹数据；它只会得知系统的检查是否通过。以这种方式保护的密钥，在设备上注册了新的面容或手指后将变得不可用，因此得知您密码的人无法把自己加进去并读取该密钥。

## 哪些内容会离开您的设备

只存在三种网络流量，而这三种都由您选择。

**1. 发往您所连接的服务器。** SSH 流量，在您的设备与服务器之间端到端加密：您的用户名、您密钥的签名或您的密码、您输入的内容，以及服务器返回的内容。当连接经由 Cloudflare Tunnel 传输时，Cloudflare 转发加密的 SSH 字节但无法读取它们；host key 验证保护您免受隧道本身的威胁。服务器会像任何服务器一样保留自己的登录记录。

**2. 发往 Cloudflare，针对您标记为经隧道连接的主机。** 本应用询问主机由哪个 Access 应用程序保护，获取 Cloudflare 的签名密钥，在系统浏览器中打开登录页面，收集由此产生的令牌，并在打开隧道时向 Cloudflare 出示该令牌。登录本身在浏览器中进行，由 Cloudflare 和您的身份提供方完成；本应用从不看到您在那里输入的密码。所有这些都发往 Cloudflare 自己的端点，与您使用 Cloudflare 自己的工具时相同。Cloudflare 对此记录什么，受 Cloudflare 的隐私政策和您与其之间的协议约束。

**3. 发往 iCloud，仅当您开启时。** 见下一节。

没有任何内容发送给开发者。没有开发者服务器、没有分析 SDK、没有崩溃报告器，也没有跟踪域名。本应用在 App Store 的隐私标签写着“未收集数据”，因为事实如此。

与任何 SSH 客户端一样，您所在网络的运营者可以看到您的设备连接到哪些主机名。连接的内容是加密的。

## iCloud 同步

iCloud 同步在您于设置中开启之前处于**关闭**状态。开启后：

- **您的连接列表、片段和已知 host key** 通过您自己的 iCloud 账户、在本应用位于其中的私有数据库里同步，同时同步的还有您 SSH 密钥的非机密信息（名称、算法、公钥部分、fingerprint、创建日期，以及该密钥是否受 Face ID/Touch ID 或口令保护、是否存放在 iCloud Keychain 中），以便列表在您的其他设备上也有意义。Apple 对这些数据进行传输中和静态加密。开发者无权访问这些数据。Apple 自身能否读取，取决于您的 iCloud 账户设置，而不是本应用。
- **SSH 私钥仅在您创建或导入该密钥时为它选择了 iCloud Keychain，且它未受 Face ID 或 Touch ID 保护时才会同步。** 此时它通过 iCloud Keychain（Apple 的端到端加密钥匙串同步）传输，前提是您的设备已开启 iCloud Keychain。**密码从不同步**；每台设备都会再次向您询问密码。
- **受 Face ID 或 Touch ID 保护的密钥从不同步。** Apple 不允许，本应用也不会尝试。它们只存在于您创建或导入它们的设备上。
- **命令历史、最近打开的会话列表和诊断信息从不同步**，无论开关状态如何。
- **Cloudflare Access 令牌、服务令牌和设置不属于同步范围。** 每台设备各自登录 Access，或再次向您询问服务令牌。

同步意味着“在登录了您 Apple 账户的每台设备上都相同”。您在一台设备上信任的 host key，对于其他设备尚未接触过的主机而言，在其他设备上也被信任。如果另一台设备发送的密钥与本设备已经信任的密钥不同，本应用不会应用它：本设备保留自己已有的密钥，并在“设置 → iCloud”中显示这一分歧，由您选择保留哪一个密钥。您允许同步的密钥会出现在每台被 iCloud Keychain 信任的设备上。

由于您的 iCloud 账户此时可以访问您的连接列表、您保存的 host key 以及您允许同步的任何密钥，该账户便成为保护您服务器的一部分。请为您的 Apple 账户保持开启双重认证。

关闭开关即停止同步；已在各设备上的数据仍保留在那里。**删除所有数据**会从 iCloud 以及本设备中移除本应用的数据。如果您的另一台设备已经同步了副本，请在那台设备上也运行“删除所有数据”。

## 命令历史

默认关闭。如果您开启，本应用会记录您输入的最近 500 条命令，仅在本设备上，设备锁定时加密，并排除在备份之外。它不会过滤机密信息：在命令行上输入的密码会被原样记录，正如您 shell 自身的历史记录会记录的那样。本应用不试图过滤这些内容，因为一个大多数时候有效的过滤器会获得超出其应得的信任。关闭历史记录会删除该文件。之后再次开启则从零开始。

## 诊断

设置中可以导出诊断报告，以协助解答支持问题。它不包含任何命令、终端输出、密码、密钥或令牌，也不包含完整的主机名。在写入每一行日志的那一刻，主机名就被替换为简短的单向摘要，只保留名称的最后两段（`bastion.corp.example.com` 会变成 `<host:…>.example.com`；IP 地址会变成 `<ip>`），令牌则被替换为其长度和摘要，因此导出的内容是所记录内容的副本，而不是可能有遗漏的事后清理。报告只在屏幕上显示，除非您选择分享，否则不会保存在任何地方。是否分享、与谁分享由您决定；本应用不会把它发送到任何地方。如果您把它发送给开发者，它只会在解答您的问题所需的时间内保留。

## 开发者会收到什么

从本应用不会收到任何内容。Apple 可能会向开发者显示汇总的 App Store 统计数据，以及（如果您在设备的“分析”设置中选择了“与应用开发者共享”）iOS 收集的崩溃日志。那是 Apple 的机制，在 Apple 的隐私政策中有说明；本应用不对其添加任何内容，也不包含自己的崩溃报告器。

## 您对数据的权利

本应用持有的一切都在您的设备上或您自己的 iCloud 账户中，由您掌控。开发者处没有副本，因此开发者没有任何内容可以应您的请求提供、更正或删除。要查看您的数据，请打开本应用。要删除数据，请见下文。如果您认为开发者仍持有关于您的某些信息，请写信至 [developer contact email]。

## 删除全部内容

**设置 → 删除所有数据**会关闭每一个打开的会话，并从本设备移除每一个连接、SSH 密钥、已保存密码、Cloudflare Access 登录、片段、命令历史条目、最近打开的会话列表以及每一个已知 host key，如果同步曾经开启，还会移除本应用在 iCloud 中的数据。单个 host key 也可以在**设置 → 已知主机**中移除。

**删除本应用**会从设备中移除其文件。iOS 不承诺在删除应用时移除该应用的 Keychain 项目，因此，如果您希望密钥、密码和令牌也一并清除，并在同步曾经开启时清除 iCloud，请先运行“删除所有数据”。

这两项操作都不会改变您服务器上或 Cloudflare 处的任何内容。要在那里撤销访问权限，请从服务器的 `authorized_keys` 中移除公钥，或在您的 Cloudflare Zero Trust 控制面板中吊销会话。

## App Store 隐私标签

收集的数据：无。跟踪：无。本应用的隐私清单声明了它使用的两个需要说明理由的 API（用于其自身容器的文件时间戳，以及用于设置的标准偏好设置），未声明任何收集的数据类型，也未声明任何跟踪域名。

## 儿童

本应用是用于管理服务器的工具，并在 App Store 上据此分级。它不收集任何人、任何年龄段的数据。

## 变更

本政策的新版本随本应用的新版本一同发布，并在顶部标注日期。如果本应用将来开始向新的地方发送数据，会在此处以明白的文字事先说明，而不是事后说明。
