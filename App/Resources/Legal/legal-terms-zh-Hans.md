## 2. 本应用是什么

SuperTerminal 是一款 SSH 终端。它连接到您选择的服务器——直接连接，或通过 Cloudflare Tunnel 连接并在系统浏览器中完成 Cloudflare Access 登录——并向您显示该服务器上的 shell。这就是本产品的全部。

您无需也不会在开发者处拥有任何账户，开发者不运营任何服务器，开发者也不托管任何内容。本应用完全运行于您的设备、您所连接的服务器以及（当您使用经隧道连接的主机时）代表您行事的 Cloudflare 之间。隐私政策确切说明了本应用存储哪些内容以及存储在何处。

## 3. 您的服务器，您的权限

您只能使用本应用连接到您获准访问的系统：您拥有的系统、您管理的系统，或其所有者已授权您访问的系统。未经授权访问计算机在大多数国家/地区均属违法行为，而本应用无法判断您是否获准使用某台机器。您有责任遵守您所在地和服务器所在地的法律，并遵守您的雇主或组织关于远程访问的任何政策。

本应用将您输入的内容发送到您所连接的服务器，并显示服务器返回的内容。您输入的一切都以您登录所用的账户在该服务器上运行。您在该 shell 中所做的一切均由您负责。开发者无法看到您的会话，无法访问您的服务器，也无法恢复您在服务器上更改或删除的任何内容。

## 4. 您的凭据

本应用将 SSH 私钥、密码和 Cloudflare Access 令牌存储在您的设备上，以便您无需每次重新输入。它只将凭据发送给您正在向其进行身份验证的服务器，或者（对于 Access 令牌）发回 Cloudflare。它从不将凭据发送给开发者，因为开发者没有任何地方可以接收。

您有责任保障您设备的安全：设备密码、生物识别注册，以及谁能解锁该设备。能够解锁您的设备并打开本应用的人，可以使用其中存储的连接和凭据，但受您为个别密钥所选择的任何 Face ID 或 Touch ID 保护的约束。

## 5. Host key 与首次连接

首次连接到某服务器时，本应用会向您显示该服务器的密钥 fingerprint 并请您确认。确认一个您未与服务器核对过的 fingerprint，意味着信任任何应答的一方。本应用无法替您验证首次连接；只有您自己能做到。在之后的连接中，本应用会拒绝已更改的密钥，直到您决定如何处理。它不会自行接受已更改的密钥，链路中断后的重新连接也要经过同样的检查。

本应用以 Cloudflare 自己的命令行工具的方式与 Cloudflare 通信。如果 Cloudflare 更改了这一行为，经隧道的连接可能会停止工作，直到本应用更新为止。开发者会尽力跟进，但不承诺一定能做到。不支持 Cloudflare 的 FedRAMP 端点。
