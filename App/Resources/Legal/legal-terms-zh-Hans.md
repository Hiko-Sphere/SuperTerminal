## 1. 本条款的适用范围

本条款适用于由 Li Yanpei（“开发者”）在 App Store 上发布的 iOS 和 iPadOS 版 Apex Terminal 应用（“本应用”）。无需创建账户。本应用首次打开时会显示本条款、隐私政策和用户须知，并请您接受；此后继续使用本应用即表示您接受本条款。如果您不接受本条款，请删除本应用。

本条款是本应用的许可协议。它取代 Apple 的标准《许可应用程序最终用户许可协议》，并在第 14 条中包含 Apple 要求的条款。

## 2. 本应用是什么

Apex Terminal 是一款 SSH 终端。它连接到您选择的服务器——直接连接，或通过 Cloudflare Tunnel 连接并在系统浏览器中完成 Cloudflare Access 登录——并向您显示该服务器上的 shell。围绕这一点，它做的是 SSH 客户端会做的事：通过 SFTP 传输文件，并可将服务器发布到“文件”App；转发端口；通过 VNC 打开远程屏幕；以及在您选择信任某台服务器时，向它提供您的密钥。这就是本产品的全部。

您无需也不会在开发者处拥有任何账户，开发者不运营任何服务器，开发者也不托管任何内容。本应用完全运行于您的设备、您所连接的服务器以及（当您使用经隧道连接的主机时）代表您行事的 Cloudflare 之间。隐私政策确切说明了本应用存储哪些内容以及存储在何处。

## 3. 您的服务器，您的权限

您只能使用本应用连接到您获准访问的系统：您拥有的系统、您管理的系统，或其所有者已授权您访问的系统。未经授权访问计算机在大多数国家/地区均属违法行为，而本应用无法判断您是否获准使用某台机器。您有责任遵守您所在地和服务器所在地的法律，并遵守您的雇主或组织关于远程访问的任何政策。

本应用将您输入的内容发送到您所连接的服务器，并显示服务器返回的内容。您输入的一切都以您登录所用的账户在该服务器上运行。您在该 shell 中所做的一切均由您负责。开发者无法看到您的会话，无法访问您的服务器，也无法恢复您在服务器上更改或删除的任何内容。

## 4. 您的凭据

本应用将 SSH 私钥、密码和 Cloudflare Access 令牌存储在您的设备上，以便您无需每次重新输入。您在 Secure Enclave 中生成的密钥性质不同：私钥在芯片内部生成，本应用永远无法获得它，并且可以设置为每次使用都需要 Face ID 或 Touch ID。它只将凭据发送给您正在向其进行身份验证的服务器，或者（对于 Access 令牌）发回 Cloudflare。它从不将凭据发送给开发者，因为开发者没有任何地方可以接收。

您有责任保障您设备的安全：设备密码、生物识别注册，以及谁能解锁该设备。能够解锁您的设备并打开本应用的人，可以使用其中存储的连接和凭据，但受您为个别密钥所选择的任何 Face ID 或 Touch ID 保护的约束。

## 5. Host key 与首次连接

首次连接到某服务器时，本应用会向您显示该服务器的密钥 fingerprint 并请您确认。确认一个您未与服务器核对过的 fingerprint，意味着信任任何应答的一方。本应用无法替您验证首次连接；只有您自己能做到。在之后的连接中，本应用会拒绝已更改的密钥，直到您决定如何处理。它不会自行接受已更改的密钥，链路中断后的重新连接也要经过同样的检查。

您也可以选择信任某个证书颁发机构，此后由它签发的 host key 将被接受，而无需逐台主机作出决定。这是您对信任谁作出的选择，并且适用于该机构签发的每一台主机。

## 6. Cloudflare

Cloudflare Tunnel 和 Cloudflare Access 是 Cloudflare, Inc. 的服务，您在您自己的 Cloudflare 账户下、依照 Cloudflare 自身的条款（而非本条款）使用它们。Apex Terminal 与 Cloudflare 无关联关系，也未获得 Cloudflare 的认可或赞助。Cloudflare、Cloudflare Tunnel 和 Cloudflare Access 是 Cloudflare, Inc. 的商标。

本应用以 Cloudflare 自己的命令行工具的方式与 Cloudflare 通信。如果 Cloudflare 更改了这一行为，经隧道的连接可能会停止工作，直到本应用更新为止。开发者会尽力跟进，但不承诺一定能做到。不支持 Cloudflare 的 FedRAMP 端点。

## 7. iCloud、备份与数据丢失

本版本不通过 iCloud 同步任何内容。您的数据在您创建它的那台设备上，唯一能移动它的方式是您自己导出的备份文件。包含私钥的备份会用您选择的密码加密，而该密码不存储在任何地方：没有它，任何人都无法打开该文件，包括开发者——开发者既没有该密码的副本，也没有其他任何内容的副本。

在 Secure Enclave 中生成的密钥根本无法导出——既不能进入备份，也不能转移到另一台设备。这是硬件的属性，而非本应用的限制。设备一旦丢失，此类密钥即随之丢失，您需要从您的服务器上移除其公钥部分。

保存备份以及保管备份密码是您的责任。iCloud、Face ID、Touch ID 和 Secure Enclave 是 Apple Inc. 的服务与功能，受您与 Apple 之间的协议约束。

## 8. 转发

本应用可以双向转发端口、提供 SOCKS5 代理，并且在您为某条连接开启后，允许该服务器上的程序请求您的设备用这条连接所使用的密钥进行签名。

这些功能会通过您的连接承载其他流量，而这些流量是什么仍由您负责：第 3 条的规则适用于您通过转发所到达的一切，而不仅适用于您在 shell 中输入的内容。代理转发默认关闭，按连接单独开启。在它开启且会话打开期间，该服务器上具有足够权限的任何程序都可以请求您的设备签名，包括为通往其他服务器的连接签名。本应用在您开启它的位置明确说明了这一点；判断哪些服务器值得开启，则由您决定。
