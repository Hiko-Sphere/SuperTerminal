# SuperTerminal — 用户须知

这是本应用如何处理您密钥的通俗说明。它不是隐私政策，也不是使用条款；它是在您把任何东西托付给本应用之前应当阅读的页面。

## 本应用做什么

- 打开到您添加的服务器的 SSH 会话，直接连接或通过 Cloudflare Tunnel 连接。
- 对于经隧道连接的主机，在系统浏览器中让您登录 Cloudflare Access，并使用由此产生的令牌代表您打开隧道。本应用从不看到您的 Cloudflare 密码。
- 将您的连接、密钥、密码、Access 令牌、host key 和片段存储在您的设备上，使您无需重新输入。
- 可选地通过您自己的 iCloud 账户，在您自己的设备之间同步连接、片段、host key 以及您选择的私钥。密码从不同步。

## 本应用不做什么

- 它没有账户、没有服务器、没有分析、没有崩溃报告器，也没有遥测。不会向开发者发送任何内容。
- 它从不将凭据发送到任何地方，除了发送给您正在向其进行身份验证的服务器，或将 Access 令牌发回 Cloudflare。
- 它从不削弱 TLS 检查或 host key 检查。不存在任何设置——无论隐藏与否——会在不询问您的情况下接受无效证书或已更改的 host key。
- 它从不将您的终端输出写入磁盘。回滚内容仅存于内存。
- 除非您开启命令历史，否则它不记录您输入的内容。关闭历史记录会删除记录，而不是隐藏记录。
- 它不会从命令历史中过滤机密信息，因为一个大多数时候有效的过滤器比没有过滤器更糟。如果您开启历史记录并在命令行上输入密码，它会被记录下来，正如您的 shell 会记录的那样。
- 除非您开启 iCloud 同步，否则它不同步任何内容。

## 您的密钥存放在哪里

- **在设备上：** 存放于 Apple 的 Keychain 中，仅在设备解锁时可读。iCloud 同步关闭时，每个项目都标记为仅限本设备，无法通过 iCloud Keychain 传输，也无法通过恢复到另一台设备的备份传输。您还可以额外用 Face ID 或 Touch ID 锁定密钥。以这种方式锁定的密钥与当前注册的生物识别信息绑定；注册新的面容或手指会使其不可用，因此得知您密码的人无法把自己加进去并读取它。
- **在 iCloud 中，仅当您开启同步时：** 私钥仅在您为它选择了 iCloud Keychain、且它*未*受 Face ID/Touch ID 保护时才会同步。它通过 iCloud Keychain 传输，Apple 对其进行端到端加密。密码从不同步。受生物识别保护的密钥从不离开设备。Apple 不允许，本应用也不会尝试。
- **别无他处。** 私钥从不发送到服务器；服务器看到的是用它生成的签名。

## 保护了什么，以及如何保护

**有人冒充您的服务器。** 每次连接都会验证服务器的 host key。您从未连接过的服务器必须由您确认，其 SHA-256 fingerprint 会显示在屏幕上。密钥自上次以来已更改的服务器会被拒绝；本应用显示两个 fingerprint 并等待。链路中断后的重新连接也要经过同样的检查。

**有人处于您与 Cloudflare 之间。** TLS 由操作系统验证。本应用不包含任何接受错误证书的方式。

**有人操纵 Cloudflare 登录。** 本应用只接受经 Cloudflare 签名的登录信息，并且只接受 `cloudflareaccess.com` 之下的登录域名。服务器无法通过本应用把您引向伪造的登录页面。

**有人窃取或重用 Access 令牌。** 令牌在发送前会检查签名、受众、签发者和有效期。一个 Access 应用程序的令牌不能用于另一个。

**您的日志。** 您输入的任何内容和服务器打印的任何内容都从不记录到日志中。主机名和令牌在写入每一行日志时即被脱敏，而不是事后清理，因此诊断导出就是所记录内容的副本。脱敏只保留服务器名称的最后两段（`<host:…>.example.com`）；IP 地址会变成 `<ip>`。

**重试。** 只有网络和隧道故障会自动重试。被拒绝的 host key、失败的证书检查、被拒绝的密码或被拒绝的 Access 登录都会停止并向您显示错误。本应用不会越过安全检查进行重试。

**传输加密。** SSH 仅使用带认证的加密算法：AES-GCM、ChaCha20-Poly1305，或采用先加密后 MAC 的 AES-CTR。没有 CBC，没有 RC4，没有未认证模式。本应用不实现任何自己的密码学；每个基元都来自 Apple 的 CryptoKit、swift-crypto、libsodium 或 OpenBSD 的 bcrypt_pbkdf。

**粘贴。** 多行粘贴在发送前会请求确认，除非您在设置中将其关闭。

**应用切换器。** “在应用切换器中隐藏内容”开启时（默认开启），只要本应用不在前台，其 logo 就会盖住终端，因此系统的应用切换器快照中不会出现任何终端内容。

## 您必须检查的内容

首次连接到某服务器时，本应用会显示该服务器的密钥 fingerprint 并请您确认。请将其与服务器自身报告的内容进行比对（对 host key 文件运行 `ssh-keygen -lf`，或询问管理该服务器的人）。如果您未经核对就确认了 fingerprint，那么您是在信任任何应答的一方；首次连接时本应用无法分辨其中的区别。此后，已更改的密钥会被拒绝，直到您查看两个 fingerprint 并作出决定。本应用不会越过该提示进行重试。

## 自动重新连接

如果连接因网络或隧道而中断，本应用会重新连接。它不会重试被拒绝的密码、已更改的 host key 或失败的证书检查；这些会停止并等待您。重新连接后，shell 是新的：工作目录不同，没有任何正在运行的程序。本应用会在终端中画一条以自身名称标注的分隔线，让您能看到断点在哪里。

## 一段话说清 iCloud

开关在您开启之前是关闭的。开启：连接列表、片段、已知 host key 以及您密钥的非机密信息进入您的 iCloud 私有数据库；您为其选择了 iCloud Keychain 的私钥（若非生物识别密钥）会经由 iCloud Keychain 传输；密码从不传输。从不：生物识别密钥、命令历史、最近打开的会话列表、诊断信息。Access 令牌留在完成登录的那台设备上。开发者无法读取其中任何内容；Apple 能否读取取决于您的 iCloud 账户设置，而不是本应用。关闭即停止同步。“删除所有数据”也会清除 iCloud。从另一台设备同步来的 host key，对于本设备尚未接触过的主机而言，在这里与您在本地确认的一样被信任，因此控制了您 iCloud 账户的人可以植入一个；而与本设备已信任的密钥不同的同步密钥则不会被应用；“设置 → iCloud”会显示这一分歧，由您选择保留哪一个密钥。由于您的 Apple 账户现在可以访问您的连接列表和 host key，请为其保持开启双重认证。

## 您必须自己做的事

1. **核对首次 fingerprint。** 如果您确认了攻击者的 fingerprint，之后到该身份的每一次连接都会被攻破，而本应用无法分辨。
2. **认真对待已更改的密钥。** 如果本应用提示密钥已更改，而您并没有重装服务器或更换其密钥，请停下来询问管理员。
3. **设置设备密码。** 上述每一项保护都以设备在您不使用时处于锁定状态为前提。
4. **为重要的密钥使用 Face ID 或 Touch ID。** 每次连接只需看一眼，却意味着仅凭被盗的密码是不够的。
5. **如果您开启 iCloud 同步，请保障 iCloud 账户的安全。** 为 Apple 账户开启双重认证是最低要求。
6. **开启历史记录时不要在命令行上输入机密信息。** 您输入什么，存储的就是什么。
7. **在服务器上吊销，而不只是在手机上。** 从本应用中删除密钥不会移除服务器 `authorized_keys` 中的公钥。设备丢失意味着要在那里吊销，并在您的 Cloudflare 控制面板中吊销 Access 会话。
8. **不要安装您不信任的根证书。** 本应用信任操作系统的信任存储区。

## 本应用无法保护您免受的情况

- 已经被攻破的设备，或他人在其上安装的受信任根证书。
- 您未经核对就确认的首次连接 fingerprint。
- 运营您网络的人看到您连接到哪些主机名。内容是加密的；目的地并未隐藏。
- 能够解锁您的设备并打开本应用的人。他们可以使用任何密钥未受生物识别保护的已存储连接。
- 在 iCloud 同步开启时，控制了您 Apple 账户的人。
- 您从终端复制的任何内容都会留在剪贴板上，直到您复制其他内容。本应用不会清除它。
- 有一个依赖项 libsodium 是以其维护者提供的预编译二进制文件形式包含的，而不是从源代码构建。其作用仅限于打开密封的 Cloudflare 登录结果（之后会另行独立验证），以及提供 ChaCha20-Poly1305 SSH 加密算法。
- 不支持 Cloudflare 的 FedRAMP 端点。

## 清除

**设置 → 删除所有数据**会关闭每一个会话，并从设备中移除每一个连接、密钥、密码、Cloudflare 登录、片段、历史条目、最近打开的会话列表以及每一个已知 host key，如果同步曾经开启，还会移除本应用在 iCloud 中的数据。单个 host key 也可以在**设置 → 已知主机**中移除。删除本应用会移除其文件，但 iOS 不承诺随之移除 Keychain 项目，因此请先运行“删除所有数据”。这两项操作都不会触及您的服务器或您的 Cloudflare 账户；请在那里从 `authorized_keys` 中移除公钥或吊销 Access 会话。

## 开源

本应用包含以 Apache-2.0（swift-nio 系列、swift-crypto）、ISC（swift-sodium、bcrypt_pbkdf）和 BSD-3-Clause（Blowfish）授权的代码。其声明包含在本应用的“设置 → 法律 → 开源许可”中。Cloudflare、Cloudflare Tunnel 和 Cloudflare Access 是 Cloudflare, Inc. 的商标；SuperTerminal 与 Cloudflare 无关联关系。
